# Curs.CS2

Сайт клана [Curs] на сервере CrazyPub для Counter-Strike 2.

## Стек
React 19, TypeScript, Vite, Tailwind CSS, Express, PostgreSQL/Drizzle, Firebase.

## Локальный запуск

1. Установите Node.js и зависимости: `npm install`.
2. Создайте переменные окружения на основе конфигурации вашего хостинга. Обязательно задайте `SESSION_SECRET` — случайную строку длиной не менее 32 символов. Не коммитьте секреты в репозиторий.
3. Настройте PostgreSQL и Firebase согласно используемым в проекте переменным окружения.
4. Запустите `npm run dev`.
5. Для проверки типов выполните `npm run lint`, для клиентской сборки — `npm run build`.

## Размещение

GitHub Pages поддерживает только статическую клиентскую сборку. В проекте есть сервер `server.ts` и API, поэтому для полноценной работы необходим Node.js-хостинг с базой данных и переменными окружения. Публикация одной папки `dist` на Pages не обеспечит работу серверных функций.

## Безопасность

- Задайте уникальный `SESSION_SECRET` в настройках хостинга (минимум 32 символа).
- Ограничьте права доступа Google OAuth только необходимыми для приложения.
- Не сохраняйте приватные ключи и секреты в GitHub.

## Изображения

Пути вида `/assets/images/...` должны соответствовать файлам в `public/assets/images/`. Альтернатива — импорт ресурсов из `src/assets` через Vite. После изменения путей убедитесь, что файлы существуют в нужном месте.
